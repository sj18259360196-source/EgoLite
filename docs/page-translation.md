# 网页翻译

地址栏内的翻译按钮打开非模态浮层。主面板提供目标语言、翻译和更多；页面声明的语言用于标题提示，未声明时显示通用标题。翻译服务实际使用自动检测，原语言可以在更多菜单中手动指定。

首次使用从更多菜单进入翻译服务设置，填写 Azure Translator 密钥及资源区域，并确认允许发送待翻译文字。配置按 Profile 保存，密钥通过 Electron safeStorage 加密，不提供明文回退。服务可能按使用量收费。清除密钥或撤销发送许可会停止该 Profile 的翻译任务。

识别到页面声明的外语后会提示翻译，中文页面不提示，同一标签的同一地址关闭后不反复提示。每次发送文字仍由用户主动触发，不自动上传网页。

点击翻译后浮层收起，地址栏图标持续显示进行中、完成或暂停状态，悬停可查看已翻译数量。再次打开浮层可暂停翻译或显示原文。暂停和错误后继续时保留已有译文，不先恢复整页。

翻译优先处理当前视口中的段落，保持段落内文字顺序，再继续其余内容。有待处理内容时连续请求，不在每批之间额外等待一秒。配置页会区分密钥可读取、未配置和无法解密三种状态；Global 资源的区域字段留空。

## 范围

- 支持普通 HTTP、HTTPS HTML 页面的主文档文字，以及动态新增文字。
- 文本按段落组合，使用稳定标记映射回原文本节点，保留链接和元素身份。
- 跳过输入框、编辑区、代码、数学公式和声明不翻译的区域。
- 不支持 PDF、图片文字、iframe 或 Shadow DOM。单文本节点超过 4000 字符时跳过。
- 单次任务设置请求超时和累计字符上限，不保证所有网站的 DOM 更新方式都兼容。
- 译文仅作为文本回填。恢复原文只撤销仍与译文匹配的节点，不覆盖网站后来写入的内容。
- 导航取消旧请求；控制权变化暂停翻译；回填和恢复会使旧 Agent 页面引用失效。

## 文件

- `apps/desktop-shell/page-translation.mjs` 负责隔离环境中的提取、回填和恢复。
- `apps/desktop-shell/translation-service.mjs` 负责服务请求、配置和任务生命周期。
- `apps/desktop-shell/public/translation.js` 与 `translation.css` 负责地址栏浮层。
- 配置保存为应用数据目录下的 `translation-settings.json`，正文不持久化。

## 验证

运行以下命令。

```powershell
node --test apps/desktop-shell/translation-service.test.mjs
node tools/translation-smoke.mjs
npm run typecheck
```

Electron 验证使用独立数据目录、独立 Broker 管道及模拟翻译响应，不读取用户浏览数据。检查实际地址栏入口、服务配置、动态文字、恢复原文、注入防护、导航取消及浮层布局，结果存放在 `output/translation-validation`。测试退出时停止创建的进程并清理本次临时目录。

2026-09-29 的源码回归还覆盖鼠标命中、自动提示、中文页面不提示、收起浮层后的状态更新和保留译文继续。真实 Azure 请求另外使用本机正式加密环境和人工编写的长页面验证，结果位于 `output/translation-ux-validation/live-result.json`。这不代表所有真实站点的翻译质量或安装升级都已验证。现有安装不会因源码修改自动更新。
