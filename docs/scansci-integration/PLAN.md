# ScanSci 内置组件升级

目标是交付可实际运行的 EgoLite 0.2.13，固定 ScanSci 官方稳定版 1.19.0，提交公开源码与安装包。

1. 保留源代码备份和独立 Git 分支，不覆盖正式浏览器数据。
2. 上游源码放在 vendor/scansci-pdf，Ego 适配放在 integrations/scansci，分别维护。新版删除的设置界面由 Ego 保留。
3. 浏览器导航、页面操作、Cookie 和 PDF 下载统一进入 Ego。连接检查不得切换工作区。旧配置保持独立于安装目录。
4. 锁定 Python 依赖，验证核心测试、Ego 适配、实际打包程序、真实检索下载与故障恢复。
5. 从验证过的程序生成安装包，核对压缩包中的运行时，公开源码和 GitHub Release。

后续升级时更新 upstream.json 和 vendor 源码，再运行独立适配器及验收。适配锚点变化应明确失败，不能静默跳过。涉及机构登录和未覆盖的浏览器事件接口，需要另行补充实际验收。
