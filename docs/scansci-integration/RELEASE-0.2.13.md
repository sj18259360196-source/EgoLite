# 0.2.13

内置 ScanSci PDF 更新至官方稳定版 1.19.0。保留 Ego 设置界面，将浏览器导航、页面操作、Cookie 和 PDF 下载接到 Ego。

- 修复连接检查切换工作区、设置页首次加载超时和启停竞态。
- 补齐服务身份与端口冲突处理，失败或未配置的通道显示真实状态。
- 固定依赖和独立 Python 运行时，强化 PDF 可读性检查与失败保留原文件。
- 配置继续保存在安装目录外，覆盖安装不以包内默认配置替换现有配置。

94 项上游测试、8 项 Ego 适配测试、118 项浏览器和组件测试通过。最终 Windows 程序已验证页面操作、Cookie 读写、带测试登录态下载、20 个 ScanSci MCP 工具、设置页和崩溃恢复。真实网络检索与 arXiv PDF 下载通过。

安装包中的完整 ScanSci 运行时与实测程序逐文件校验一致。机构账号完整登录和所有出版社路径仍未实测。本次未覆盖本机正式安装，也未将解包验证视为覆盖安装测试。
