# 0.2.14

ScanSci 新增辅助设置，可分步填写邮箱、下载目录和学校入口。支持搜索学校并自动填写，学校不在列表时可手动设置。Elsevier API、CARSI 和图书馆代理可按需启用。

配置保存增加原子写入和上一份备份，重启后保留配置与已有会话。刷新页面保留正在编辑的内容，密钥保存后不回显。登录状态显示最近检查时间，过期和网络故障分别提示。学校要求重新认证时仍需完成登录。

28 项适配测试、94 项上游核心测试和 118 项发布专项测试通过。已在最终 Windows 包实测辅助设置、重启保留、浏览器操作、带测试登录态 PDF 下载、MCP 调用和崩溃恢复。

全量检查中上一版已有的 11 项失败仍存在，涉及工作区与窗口标题等模块。外部机构账号、全部出版社及安装向导未实测，详见源码中的 ScanSci 工作日志。ScanSci 核心仍为 1.19.0。
