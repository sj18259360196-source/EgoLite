# ScanSci PDF 升级

## 0.2.14 辅助设置

新增辅助设置入口，可分步保存开放获取邮箱、下载目录、学校 WebVPN、Elsevier Key、CARSI 和图书馆代理。学校列表支持搜索和自动填写，未收录的学校可手动填写官方入口。可选通道不要求全部开启。

配置使用跨进程锁和原子替换保存，保留上一份备份。主配置损坏时从有效备份恢复，并保留损坏原件。重启后配置、密钥和已有 Cookie 保留，刷新页面不会覆盖未保存的输入。

登录状态区分会话已保存、最近验证通过、过期、网络不可达和未配置。验证结果带时间保存，超过五分钟不再作为当前有效依据。换学校或入口后旧检查结果失效。Cookie 的保留不代表机构永久登录。

28 项适配测试、94 项上游核心回归和 118 项发布专项测试通过。最终 Windows 程序已实际完成表单填写、学校自动填写、手动入口、密钥不回显、刷新草稿保留、重启后读回配置与 Cookie、内嵌页面显示、MCP 调用和服务崩溃恢复。截图已逐张查看。证据见 evidence/guided-setup.json、guided-school.png、guided-session.png、settings.json 和 windows-suite.json。

扩大范围检查发现全量 752 项测试中有 12 项失败。干净上一版源码复测有相同的 11 项失败，涉及工作区生命周期、窗口标题和旧的控制交互断言；额外扩展适配测试单独复测通过。本轮未改动这些模块，不将发布专项通过写成全仓库通过。

0.2.14 安装包已生成并通过解包一致性检查，完整比较 8,140 个 ScanSci 文件。真实机构 SSO、全部出版社和外部 Elsevier Key 未使用真实账号验收。安装向导和覆盖安装仍未实测。公开发布结果记录在 WORKLOG。

公开源码主分支已更新，Release v0.2.14 已正式发布，标题为 0.2.14。源码提交 96fabe920c3387ad268a983616f5b82ab849ca48 的分支与主分支 Windows CI 均通过，远端安装包大小及 SHA-256 与本地一致。实施源码位于 release/public-source，主工作目录原有开发改动继续保留。

## 0.2.13 历史

EgoLite 0.2.13 已将内置核心从 1.12.9 更新到官方稳定版 1.19.0，保留 Ego 设置页、原配置和浏览器登录态路径。代码在独立分支 codex/scansci-update-1.19.0 实施，没有覆盖本机正式安装或用户配置。

上游固定提交为 75efc280a2bf12d2d3c908858de4efb330a124c0。新版已移除 Web UI，Ego 自有界面与桥接作为单独适配层维护，不覆盖新版下载核心。

已通过 94 项上游核心测试、8 项 Ego 适配测试和 118 项浏览器及组件回归。类型检查和自动化接口文档检查通过。

最终 Windows 包已实测 20 个 ScanSci MCP 工具的暴露、Ego 页面输入、Cookie 导入导出、带测试登录态的 PDF 下载、设置页显示、真实配置保存、端口占用避让和崩溃恢复。真实网络已完成关键词检索，并下载和读取 arXiv 1706.03762 的 15 页 PDF。

PDF 下载会检查可读性，失败时保留原文件。浏览器检查只读，不创建或切换工作区。旧配置中的未知字段和密钥在保存其他设置后保持不变。依赖按哈希锁定，安装包使用独立 Python 运行时。

机构账号的完整 WebVPN、CARSI、EZproxy 登录和全部出版社下载路径没有实测。Ego 的 Python 页面适配层尚未完整覆盖 Playwright 事件接口，不能将本次验证扩展为全部 SSO 和出版社页面均兼容。真实检索结果仍受上游数据源排序与元数据质量影响。

安装包解包检查通过，包含完整实测运行时，共校验 8,190 个 ScanSci 文件。未覆盖本机正式安装，未实测安装向导和覆盖安装。验收记录见 [WORKLOG](WORKLOG.md)，实测结果保存在 evidence。

公开源码主分支及 GitHub Windows CI 已确认，Release v0.2.13 已发布。远端安装包大小和 SHA-256 与本地一致，校验文件同时提供。发布地址为 https://github.com/sj18259360196-source/EgoLite/releases/tag/v0.2.13 。
