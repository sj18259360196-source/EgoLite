# ScanSci 升级工作日志

## 1.19.0 适配

固定官方 v1.19.0，提交 75efc280a2bf12d2d3c908858de4efb330a124c0。升级前已保留 Git bundle 和本机旧适配代码备份。主工作目录存在其他开发改动，本轮在独立公开源码检出中进行。

新版上游移除了 Web 界面，因此保留 Ego 设置页并单独适配接口，未用旧下载核心覆盖新版核心。浏览器后端、登录入口、Cookie 和设置中的外部链接统一接到 Ego。内置模式不回退到外部浏览器。

补齐服务身份识别、占用端口避让、启动取消和重启竞态处理。未配置或失败的通道不再显示检查通过。设置页从真实 guest 页面读取内容并截图验收。

本轮发现并修复以下问题。

- 首次加载核心超过旧的 1.5 秒设置接口超时，改为预加载核心并调整等待时间。
- 浏览器可用性检查会创建和选择工作区，改成只读检查；启动恢复保留已选设置页面。
- 新版 fitz 兼容入口会向标准输出打印提示，改用 pymupdf 别名，避免污染 MCP 标准输出。
- PDF 下载后的额外元数据重命名可能拖住 Web 请求，改成显式选项。
- arXiv PDF 地址增加标准地址回退。下载先验证文档可读取，再原子替换目标文件。
- 页面抓取移植缺少 tempfile 导入，补齐并增加回归测试。
- 初次设置截图被引导页遮挡，没有作为通过证据；隔离测试预置完成引导后重新验证。
- 最终上游回归脚本缺少临时父目录，首次产生 20 个测试准备错误；创建父目录后 94 项全部通过，并同步修正 CI 准备步骤。
