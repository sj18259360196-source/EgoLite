下载通道

检查、登录与启停都在这里完成

先设置开放获取

填写常用邮箱供 Unpaywall 查询使用。没有学校账号或 API Key，也可以下载开放获取论文。

选择你的学校

选择学校后自动填写 WebVPN 入口。学校不在列表时，填写图书馆提供的名称和入口。

按需要添加通道

这些通道可以单独设置，不必全部开启。已有可用学校通道时，可以先开始下载。

Elsevier API

在 Elsevier 开发者网站登录并申请 API Key，复制到下方。Key 不等于全文订阅权限，全文访问还取决于机构授权和网络。

CARSI 机构认证

学校参加 CARSI 且订阅了目标出版社时可用。填写认证页面中的学校名称，再选择要登录的出版社。

EZproxy 图书馆代理

只有图书馆提供 EZproxy 地址时才需要设置。不要把 WebVPN 地址填在这里。

灰色源与 Tor

两个开关分别保存。开启灰色源不会自动启动 Tor，启动 Tor 也不代表机构登录有效。

保留配置和登录会话

保存后即可关闭页面或重启 Ego。已保存的 Cookie 会继续复用；学校要求重新登录时，仍需在 Ego 中完成验证码或认证。
